# kiwimaddog2020.github.io

The hub site for my research notes (https://kiwimaddog2020.github.io/).
Each note is a GitHub Pages site published from the repository it
describes. This repo holds the index, the Atom feed, AND the shared
stylesheet `assets/research-notes.css` plus the self-hosted fonts under
`assets/fonts/`: every note layout links those by absolute path, so the
filenames are a published contract. Do not move or rename them.

The notes list in `data/notes.json`, and `feed.xml`, are generated by
`bin/build_index.py`, which lists my public repositories tagged with the
`research-note` topic and uses each repo's description and homepage. Do not
edit either file by hand.

Run locally: `python3 -m http.server 8000`. Tests: `bash bin/check.sh`.

After publishing a new note, rebuild the index by hand:
`python3 bin/build_index.py` (uses `GITHUB_TOKEN` when set, anonymous
otherwise), then run the tests and commit the result. There is no CI or
scheduled automation in this repo. Removing the `research-note` topic from a
repo is the intended way to de-list it; the next rebuild drops the entry.
