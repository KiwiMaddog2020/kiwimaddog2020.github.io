# Fonts

Every font on the site is self-hosted from `assets/fonts/` and licensed under
the SIL Open Font License 1.1 (https://openfontlicense.org). The OFL allows
bundling and redistribution, including on a website, as long as the fonts are
not sold on their own. Files were taken from the `@fontsource` npm packages.

| Family | Used for | Files |
| --- | --- | --- |
| Bricolage Grotesque (variable) | headings, navigation, cards | `bricolage-grotesque-latin*.woff2` |
| Source Serif 4 | reading text | `source-serif-4-*.woff2` |
| Source Sans 3 | labels and tables | `source-sans-3-*.woff2` |
| Caveat 700 | handwriting (margin notes, corrections) | `caveat-700-latin.woff2` |
| Cormorant Garamond, Inter | the `/work/` page only | `cormorant-garamond-*.woff2` (upright and italic), `inter-*.woff2` |

Do not rename or remove these files: note sites in other repos load them by
absolute URL.
