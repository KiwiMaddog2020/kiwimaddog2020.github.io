# Arbiter Machinae hub site

## What this is

The hub for Kevin Madson's AI research notes, served by GitHub Pages at
https://kiwimaddog2020.github.io/. Each note is its own repo that publishes a
Pages site from its `docs/` folder; this repo holds the home page, the notes
index, the Atom feed, and the shared stylesheet and fonts every note site uses.

An upgrade is in progress. Read `UPGRADE.md` first and continue from the first
unchecked phase.

## Build, test, run

- Serve locally: `python3 -m http.server 8000` then open http://localhost:8000/
  (no build step; GitHub Pages runs Jekyll on push to main).
- Tests: `bash bin/check.sh` (runs `python3 -m pytest tests -q`).
- Rebuild the notes index and feed: `python3 bin/build_index.py`
  (uses `GITHUB_TOKEN` when set, anonymous otherwise). Run it by hand after
  publishing a note, then run the tests and commit `data/notes.json` and `feed.xml`.
- Cache stamps: `python3 bin/stamp-cache.py` before committing asset changes
  (or enable the hook once with `git config core.hooksPath .githooks`).

## Layout

- `index.html` + `assets/home.css` home page (research only; the note cards
  between the `notes:start` / `notes:end` markers are generated).
- `_layouts/default.html` layout for Markdown pages.
- `assets/research-notes.css`, `assets/notebook.js`, `assets/fonts/` shared
  with every note site.
- `data/notes.json`, `feed.xml` generated by `bin/build_index.py`;
  `data/notes-meta.json` hand-written card text; `data/figures/` figure data.
- `rag-findings/`, `work/` standalone pages.
- `bin/` scripts, `tests/` pytest suite.
- `docs/` internal only, never published. `docs/archive/` holds old plans,
  audits and agent files: history, not rules.

## House rules

- All work lands on the session branch, one commit per phase. No pull request
  unless Kevin asks. Never force-push or rewrite history.
- No GitHub Actions, Dependabot or other CI automation. Use the local scripts.
- User-facing text: no em-dashes, PG-clean tone, plain language.
- Never skip or disable a test to get a pass.
- Questions to Kevin are 2 to 4 tap choices, never open-ended text.
- Self-hosted fonts only; no third-party origins on published pages.
- Every link must resolve. Do not hand-edit generated files.
- Every page must be complete with JavaScript off and with reduced motion on.
  Both themes (paper and chalkboard) are checked for every visual change.

## Invariants

- Do not move or rename `assets/research-notes.css`, `assets/notebook.js` or
  anything in `assets/fonts/`. Note sites in other repos link them by absolute URL.
- These class names are part of that contract: `body.hub`, `nav.top`,
  `.notes-list`, `.note-pager`, `.study-list`, `.study-link`, `.feature-tile`,
  `.skip-link`, `.to-top`.
- A note is listed when its public repo has the `research-note` topic. Removing
  the topic is how a note is de-listed. Repo description becomes the title,
  repo homepage becomes the link (validated by `_safe_page_url`; keep that check).
- An empty GitHub API result must leave `data/notes.json` and `feed.xml`
  untouched (fail-safe in `bin/build_index.py`).
- `feed.xml` must stay valid Atom; `feed.xsl` makes it readable in a browser.
- Anything new at the repo root that is not a page must be added to `exclude`
  in `_config.yml`, or Jekyll will publish it.
